Damped Oscillations

Waves & Oscillations • Part I

1. Damped Harmonic Motion

When oscillating bodies do not move back and forth between precisely fixed limits because frictional forces dissipate the energy, and the amplitude of oscillation decreases with time and finally dies out. Such harmonic motion is called Damped Harmonic Motion.

Various physical damping mechanisms contribute towards damping, such as friction between the mass and a table, air resistance, or internal friction in a spring.

2. The Damped Mass-Spring System

We model these mechanisms by introducing a damping force which is proportional to the velocity of the oscillator.

Damping Force: F' = -bv

Newton's Second Law for horizontal forces:
ma = -kx - bv

m(d2x/dt2) = -kx - b(dx/dt)

We can rewrite the differential equation as:

d2x/dt2 + γ(dx/dt) + ω02x = 0

Where:

  • ω0 = √(k/m) (Natural angular frequency)
  • γ = b/m (Damping constant, unit: s-1)

3. Solving the Damped Oscillator Equation

Assuming a solution of the form x = Bept, the auxiliary equation becomes:

p2 + γp + ω02 = 0

Using the quadratic formula, the roots are:

p = -γ/2 ± √(γ2/4 - ω02)

We can distinguish three distinct cases based on the discriminant:

Case (i): Oscillatory Behavior (Underdamping)

Condition: ω02 > γ2/4

The solution is an oscillatory function multiplied by an exponentially decaying factor:

x(t) = Ae-γt/2 cos(ω1t + φ)

The amplitude exponentially decays with time. As γ → 0, we approach the undamped oscillator.

Case (ii): Critical Damping

Condition: ω02 = γ2/4

The roots coincide, and the system returns to equilibrium without oscillating. The condition is referred to as "critical damping." If ω02 < γ2/4, the system will not oscillate.

Case (iii): Overdamping

Condition: ω02 < γ2/4

The system slowly approaches the rest position without any oscillations.

4. Analogy to the RLC Circuit

The series RLC circuit (Resistor, Inductor, Capacitor) is the electrical analogue of the damped mass-spring system. According to Kirchhoff's voltage law:

VR + VC + VL = 0

iR + Q/C + L(di/dt) = 0
d2i/dt2 + (R/L)(di/dt) + (1/LC)i = 0

Comparing this to the mechanical system:

  • γ = R/L
  • ω0 = √(1/LC)

The three distinguishable cases for the RLC circuit are:

  • Oscillatory behavior: 1/LC > R2/(4L2)
  • Critical damping: 1/LC = R2/(4L2)
  • Over damping: 1/LC < R2/(4L2)
